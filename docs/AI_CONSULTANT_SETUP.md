# 🤖 Настройка AI Консультанта

## Что это?

AI Консультант - это умный помощник на базе Google Gemini AI, который помогает студентам:
- ✅ Выбрать подходящий университет
- ✅ Оценить шансы на грант
- ✅ Получить советы по поступлению
- ✅ Ответить на вопросы о требованиях

## 🔑 Получить API ключ (БЕСПЛАТНО!)

### Шаг 1: Откройте Google AI Studio

Перейдите на: **https://makersuite.google.com/app/apikey**

### Шаг 2: Войдите в Google аккаунт

Используйте свой Google аккаунт

### Шаг 3: Создайте API ключ

1. Нажмите **"Create API Key"**
2. Выберите проект или создайте новый
3. Скопируйте ключ (он выглядит так: `AIzaSy...`)

### Шаг 4: Добавьте ключ в приложение

Откройте файл:
```
lib/services/ai_consultant_service.dart
```

Найдите строку 13:
```dart
static const String _apiKey = 'YOUR_GEMINI_API_KEY_HERE';
```

Замените на ваш ключ:
```dart
static const String _apiKey = 'AIzaSy...ваш_ключ';
```

Сохраните файл!

## 💡 Лимиты бесплатного использования

- **60 запросов в минуту**
- **1500 запросов в день**
- **Полностью бесплатно** для разработки и тестирования

Этого более чем достаточно!

## 🚀 Как использовать

1. Откройте приложение
2. Нажмите на вкладку **"AI Агент"** (значок робота 🤖)
3. Задайте вопрос, например:
   - "Какой университет лучше для IT?"
   - "Какие у меня шансы на грант?"
   - "Что нужно для поступления в КазНУ?"
   - "Посоветуй университет для изучения медицины"

## ⚠️ Важно!

### Безопасность API ключа:

1. **НЕ публикуйте** код с ключом в GitHub
2. Для production используйте `.env` файл
3. Держите ключ в секрете

### Если ключ утек:

1. Откройте https://makersuite.google.com/app/apikey
2. Удалите старый ключ
3. Создайте новый

## 🔧 Troubleshooting

### Ошибка: "API key not valid"

- Проверьте, что скопировали ключ полностью
- Убедитесь, что в начале нет пробелов
- Проверьте, что ключ не истек

### Ошибка: "Quota exceeded"

- Вы превысили лимит бесплатного использования
- Подождите 24 часа или создайте новый проект

### AI не отвечает

- Проверьте интернет
- Убедитесь, что API ключ правильный
- Посмотрите логи в консоли (flutter run)
