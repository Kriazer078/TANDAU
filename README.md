## 🎯 The Problem
Каждый год сотни тысяч абитуриентов в Казахстане теряются в сложном процессе выбора университета, специальности и распределения грантов. Недостаток структурированной информации и стресс приводят к ошибкам, которые стоят бюджетного места.

## 💡 Our Solution
**TANDAU** — это умный компаньон абитуриента. Мы объединили актуальные данные МОН РК и мощь искусственного интеллекта, чтобы сделать качественное высшее образование понятным и доступным.

---

## ✨ Features

- 🚀 **AI-Оценка шансов на грант:** Введите баллы ЕНТ и получите точный расчет вероятности поступления по топовым вузам на одном экране.
- 🧠 **Умный AI-Консультант:** Ваш персональный ментор на базе Gemini 1.5 Pro. Знает всё о квотах, дедлайнах и правилах приема.
- 🏫 **Офлайн-каталог вузов:** 50+ ведущих университетов, актуальные проходные баллы, стоимость обучения и живые отзывы. Сравнивайте фаворитов в пару свайпов.
- ⚡ **Seamless Experience:** Молниеносная производительность, современный UI (Glassmorphism) и поддержка 3-х языков (RU, KZ, EN).

---

## 🛠 Tech Stack

- **Frontend:** Flutter & Dart (Riverpod, Custom Design System)
- **Backend:** Собственный микросервис на Dart Shelf (Render)
- **Инфраструктура:** Firebase (Firestore, Auth, Remote Config)
- **AI Core:** Google Gemini API (с поддержкой Google Search Grounding)
