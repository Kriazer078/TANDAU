# TANDAU - Talent Analysis & Navigation for Dream University

**TANDAU** — мобильное приложение на Flutter для помощи студентам 11 классов в выборе университета в Казахстане.

## 🎯 Особенности MVP

- **Фильтрация** по городу, специальности и бюджету
- **Поиск** университетов
- **Детальная информация**: местоположение, специальности, проходной балл, стоимость, общежитие, гранты, требования, сроки
- **Избранное** - сохранение университетов
- **Современный UI** с Material Design 3

## 🚀 Запуск

### Установка зависимостей
```bash
flutter pub get
```

### Запуск приложения
```bash
flutter run
```

## 📦 Пакеты

- `google_fonts` - Шрифт Inter
- `shared_preferences` - Хранение избранного
- `intl` - Интернационализация

## 🏗️ Структура

```
lib/
├── main.dart
├── theme/              # Цвета и тема
├── models/             # Модели данных
├── data/               # Примеры университетов (10 шт)
├── services/           # Бизнес-логика
├── widgets/            # Переиспользуемые компоненты
└── screens/            # Экраны приложения
```
