# Алгоритм работы:
1. **Анализ контекста:** Прежде чем менять код, прочитай существующий файл, чтобы не удалить важные функции.
2. **Безопасность Firebase:** - Проверяй права доступа (Rules).
   - Никогда не хардкодь API ключи.
3. **Защита данных:** При работе с данными студентов (баллы, ФИО) используй шифрование или защищенные хранилища (flutter_secure_storage).
4. **Мелкие исправления:** Если видишь устаревший код (deprecated), исправляй его сразу, не дожидаясь моей просьбы.
